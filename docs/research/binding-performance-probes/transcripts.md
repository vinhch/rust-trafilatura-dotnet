# Probe transcripts

The harness is `docs/research/binding-performance-probes/`; its README names every case and its exact
command. Everything below was run on the section 1 host with .NET SDK 10.0.401, and a row labelled
`compiled` in `../binding-performance.md` or `../binding-performance-recommendations.md` points here.
Transcripts are the compiler's own lines and the programs' own output, presented condensed below rather
than as raw logs. MSBuild's banner, restore lines and elapsed times are omitted; each diagnostic line's
`[<project>.csproj]` suffix is stripped, and so is the trailing
`(https://learn.microsoft.com/dotnet/fundamentals/syslib-diagnostics/syslibXXXX)` link that the SYSLIB
analyzers append; the copy of the diagnostics MSBuild repeats under its build summary is dropped; and
repository paths are shortened to the project directory. The CompileProbe section records one outcome
per case and configuration instead of a build log, so each compiling build's warnings are not
reproduced, and its `CASE_LANGVER` lines elide the compiler path and the repeated middle of the message
with `...`. The Native AOT publish is reduced to the publish steps the document cites and the published
app's failure, with the analyzer warnings it repeats from the build above dropped as its caption says;
the `[exit 0]` there is the command's exit code, added here.

The timing and allocation figures in sections 1 and 6 of `../binding-performance.md` come from scratch
harnesses (`Eval`, `AllocProbe`) that are not committed here; the method and host are stated with those
tables. Every figure the committed harness produces is transcribed below.
